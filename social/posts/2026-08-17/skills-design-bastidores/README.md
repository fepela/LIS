Este Reel foi **construído usando as 3 skills** que ele explica — pilar **bastidores**:
- **`design-taste-frontend` (Taste):** definiu o "Design Read" e a estética (capa com um mock

## Legenda sugerida

Instalei 3 skills de design na IA — e este Reel foi feito com elas. (sim, um belo paradoxo 😄) 🔷

Skill é uma pasta de instruções que o Claude Code carrega sozinho quando a tarefa aparece. Coloquei três que mudam o jogo pra quem cria conteúdo e interface:

1. Taste (design-taste-frontend) — dá bom gosto pra IA. Ela lê o briefing e escolhe a direção certa, entregando layout que não parece template. Menos "slop", mais decisão de design.

2. Motion (emilkowalski-motion) — inspirada no Emil Kowalski. Micro-interações e transições só com transform/opacity, uma linguagem de movimento só, sem exagero. Movimento que ajuda a entender, não que distrai.

3. Impeccable — trata cada tela como um diretor de arte premiado: hierarquia, tipografia, cor e motion, com craft de verdade e verificação. O acabamento final.

O melhor: dá pra usar as três juntas. Este próprio Reel — a capa que se transforma de "antes" pra "depois", o ritmo das animações, o acabamento — saiu delas.

É esse o pulo do gato das skills: você ensina o bom gosto uma vez, e a IA repete do seu jeito, toda vez.

Salva pra montar as suas. 👇
